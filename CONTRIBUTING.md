# Internal Development Guidelines

**LATTRIX is a proprietary product.** These guidelines apply to internal development teams only.

## Internal Contributors

If you're part of the LATTRIX team, follow standard development practices:

- Create feature branches from `main`
- Test before pushing
- Ensure code passes CI/CD checks
- Get code review from a maintainer
- Follow commit message conventions

## Reporting Issues

- **Technical**: Direct Slack/internal channels
- **Security**: security@lattrix.dev (confidential)
- **Production**: incident@lattrix.dev

---

*For more information, contact your team lead.*
